# Reference summaries

These compact CSV files contain the reported numerical summaries used to check a fresh run of the public code. They are included as validation targets, not as substitutes for rerunning the analysis.

- `simulation_reported_method_summary.csv`: strict-positivity main simulation and NHANES-like high-revelation experiment.
- `simulation_reported_coefficient_summary_n2500.csv`: coefficient-level summaries underlying Supplementary Tables 1--2; median SE is recomputed from the saved replicate-level results.
- `bootstrap_reported_method_summary.csv`: four reported targeted-bootstrap cells.
- `nhanes_reported_*.csv`: descriptive, coefficient, sanity-check, and diagnostic summaries for the final NHANES analysis.
